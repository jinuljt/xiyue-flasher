喜悦刷机程序 · 安装与恢复

当前只交付刷机程序的范围、设备档案和验收要求；没有可执行的刷机工具，不执行任何 USB 操作。

职责

Windows 图形向导负责识别设备、核对型号与固件、指导连接、备份、安装、校验和展示设备配置入口。日常工作不依赖 Windows 电脑。

执行流程

  1. 读取设备身份并匹配档案，不将档案中的目标信息当作实际检测结果。
  2. 检查供电、数据线、驱动、镜像来源、完整性与兼容性。
  3. 记录当前分区，先备份并验证，成功后才允许进入刷写。
  4. 用户明确确认后执行刷写；失败时保持现场并提供恢复步骤。
  5. 校验写回结果、重启、发现设备，显示配置地址与配对入口。

仓库边界

不保存用户设备地址、序列号、备份分区、私钥或含凭证镜像。发布包中的镜像必须单独验证来源、许可证和校验值。不会把某次实验的设备专属补丁当成通用固件。依赖 Agent 的安装包与设备接口，不依赖云端付费服务。

验收前置条件

Agent 真机运行与恢复机制、配对接口和发布包格式稳定后，才实现实际刷写。自动化检查仅验证 profiles/*.json 中的目标资料，不代表检测或兼容性实测。
